# Datos

El dataset completo utilizado en este proyecto no se incluye en el repositorio debido a su tamaño.

## Fuente

El análisis parte de los datasets **Glassdoor Job Reviews** de David Gauthier y de una versión preparada para la actividad del máster.

El archivo utilizado durante el desarrollo fue:

`glassdoor_reviews_hr.parquet`

## Uso

Para reproducir el análisis:

1. Obtén el dataset correspondiente.
2. Coloca el archivo `glassdoor_reviews_hr.parquet` dentro de esta carpeta `data/`.
3. Ejecuta el notebook principal desde el inicio.

La estructura esperada sería:

```text
data/
├── README.md
└── glassdoor_reviews_hr.parquet
```

## Variables principales

Entre las variables utilizadas en el proyecto se encuentran:

- `firm`: empresa
- `date_review`: fecha de la reseña
- `current`: empleado actual o antiguo
- `overall_rating`: valoración general
- `recommend`: recomendación de la empresa
- `pros`: aspectos positivos
- `cons`: aspectos negativos

## Nota

No se deben subir al repositorio datasets grandes ni archivos con información personal innecesaria.
